# 🎨 Content Factor Design System

This folder contains the **visual DNA** of Content Factor:  
- **Tokens** → atomic values for color, typography, spacing, borders, shadows.  
- **Prompts** → reusable image prompt fragments for icons, UI, navigation, and emoji‑style assets.  
- **Brand Kit** → logo lockups, palette, typography, and usage rules.

---

## ✨ Design Rationale

Content Factor is about **clarity, proof‑of‑work, and visibility**.  
The design system reflects this through:

- **Pipeline Colors** → each stage (Build, Capture, Transform, Publish, Measure) has its own color, making the process instantly legible.  
- **Typography** → Inter for clarity, Space Grotesk for personality, JetBrains Mono for technical credibility.  
- **Spacing & Borders** → modular rhythm (4/8/16/32px) and rounded corners for a modern, approachable feel.  
- **Shadows** → subtle depth to emphasize hierarchy without clutter.  
- **Prompts** → tokenized fragments ensure generated imagery stays consistent with the brand.  

---

## 📦 Usage

- **Frontend** → Tokens flow into Tailwind v4 for UI consistency.  
- **Publishing** → Templates reference tokens for Markdown, dashboards, and social outputs.  
- **Imagery** → Prompts provide a shared vocabulary for generating icons, UI mockups, and emoji assets.
