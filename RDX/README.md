# RDX Directory Index

This directory is the authoritative workspace for RDX mission briefs, plans, reports, and todos.

## Structure
- `RDX/agent_mission_briefs/`: Mission briefs and operational instructions.
- `RDX/plans/`: Planning artifacts and phase plans.
- `RDX/reports/`: Audits, AARs, and phase reports.
- `RDX/todos/`: Focused todo lists by domain.
