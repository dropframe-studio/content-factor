## 🚀 Quick Start

```bash
# Capture a commit
pnpm capture:commit

# Capture a retro
pnpm capture:retro

# Run full pipeline
pnpm pipeline

# View dashboard
cd web_app && pnpm dev
```

## 🎯 What Content Factor Does

**Captures Work:**
- Git commits → Build Logs
- Sprint retros → Progress Snapshots

**Transforms Into Content:**
- Applies structured templates
- Generates publishable Markdown

**Visualizes:**
- Dashboard UI at `http://localhost:3000`
- Real-time metrics and artifact browsing
